# InMusic 1.16 — комнаты и последовательное воспроизведение

## Комнаты
- Обновлена визуальная структура комнаты: отдельная панель «Сейчас играет», статус эфира, список участников, блок голосования, очередь и чат.
- После завершения 15-секундного голосования сервер добавляет победившую композицию в `queue`. Клиент отслеживает увеличение очереди и запускает добавленную песню через общий нижний плеер.
- Для комнаты формируется очередь из доступных треков библиотеки, чтобы участники могли слушать добавленные композиции последовательно.

## Альбомы
- При запуске альбома очередь передаётся целиком в общий плеер.
- Следующая композиция выбирается по порядку треков из `songs/` (имена с префиксами `01 -`, `02 -` и т. п.).
- Включено предварительное буферизование следующего трека и защита от двойного перехода по событию `ended`.

## Примечание
Автоматический переход запускается браузером после окончания текущего файла. Точное gapless-воспроизведение без единого сэмпла тишины зависит от браузера, формата MP3 и кодирования исходных файлов; для абсолютно бесшовных альбомов сами мастер-файлы должны быть подготовлены с корректными границами треков.
