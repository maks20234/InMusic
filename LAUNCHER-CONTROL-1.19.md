# InMusic 1.19 — управление запуском серверов

Во всех лаунчерах теперь доступны команды управления сервером. После изменения системных файлов Python/сервера выполни перезапуск, чтобы изменения вступили в силу.

## Команды

Запуск (пример для ZeroTier):
```bash
./run-zerotier.sh start
```
Остановка:
```bash
./run-zerotier.sh stop
```
Перезапуск после изменений:
```bash
./run-zerotier.sh restart
```
Проверка состояния:
```bash
./run-zerotier.sh status
```
Просмотр журнала:
```bash
./run-zerotier.sh logs
```

Те же команды работают с `run-linux.sh`, `run-lan.sh`, `run-radmin-vpn.sh` и `run-public.sh`. Если команда не указана, выполняется `start`.

Процесс работает в фоне; закрытие терминала не останавливает сервер. Остановка выполняется командой `stop`. PID и журнал находятся в скрытой папке `.runtime/` (`inmusic.pid`, `inmusic.log`). Не удаляй PID-файл, пока сервер работает. После обновления `app.py` или других системных файлов используй `restart`.

Режимы сохраняют прежнее назначение: `local` — только localhost; `lan`, `zerotier`, `radmin` — сетевые интерфейсы; `public` — localhost за HTTPS reverse proxy. Не открывай порт 5080 напрямую в интернет.
