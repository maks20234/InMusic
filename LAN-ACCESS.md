# Запуск InMusic для устройств в домашней сети

Для запуска сервера так, чтобы к нему могли подключаться другие устройства в той же Wi-Fi/LAN-сети, используйте `run-lan.sh`.

```bash
chmod +x run-lan.sh
./run-lan.sh
```

Скрипт слушает `0.0.0.0:5080` и выводит адреса для подключения. На телефоне, планшете или телевизоре откройте адрес вида `http://192.168.x.x:5080/` — используйте IP, который напечатал скрипт. Компьютер-сервер должен оставаться включённым, а терминал с сервером — открытым.

## Если другие устройства не подключаются

- Убедитесь, что устройства подключены к одной домашней сети, а не к гостевой Wi-Fi.
- В настройках роутера отключите изоляцию клиентов/AP isolation для домашней сети, если она включена.
- Проверьте firewall Linux. Если используете UFW, разрешайте порт только из своей локальной подсети, например (замените подсеть на свою):

  ```bash
  sudo ufw allow from 192.168.1.0/24 to any port 5080 proto tcp
  ```

  Не добавляйте это правило, пока не проверили свою подсеть через `ip -4 addr`.

## Важно о безопасности

- Этот режим предназначен для устройств в локальной сети. Он **не делает сайт доступным всему интернету**.
- Не настраивайте переадресацию порта 5080 на роутере и не открывайте этот порт в интернет. Для публичного доступа нужны HTTPS, защищённый reverse proxy и дополнительная проверка безопасности.
- Регистрация открыта. Первый зарегистрированный пользователь получает роль администратора. Создайте свой аккаунт до того, как сообщите адрес другим пользователям.
- Используйте уникальный пароль длиной не менее 10 символов. Не передавайте его другим.
- Сохраняйте резервную копию папки `Data`.
- Доступ по обычному HTTP в локальной сети не шифрует трафик. Используйте эту сеть только с доверенными устройствами.
