# InMusic через Radmin VPN

InMusic слушает на 0.0.0.0:5080 при запуске `./run-radmin-vpn.sh`, поэтому может принимать соединения на VPN-интерфейсе, если ОС подключена к виртуальной сети. Скрипт выводит IP-адреса интерфейсов и отдельно отмечает адреса диапазона 26.x.x.x, часто используемого Radmin VPN.

## Важное ограничение Linux

Официальная страница Radmin VPN указывает совместимость с Windows 7/8/10/11; официального Linux-клиента в списке нет. Поэтому сам InMusic можно запустить на Linux, но для прямого Radmin VPN-подключения на Linux нужен совместимый VPN-интерфейс/клиент. Неофициальные Linux-порты/обёртки существуют, но не входят в этот архив и не поддерживаются разработчиком Radmin. Если Radmin VPN запущен на отдельном Windows-компьютере, сервер InMusic на Linux не получит автоматически его виртуальный IP — потребуется отдельно настроенная маршрутизация между узлами; проще запускать InMusic на компьютере, который сам подключён к Radmin VPN, либо использовать VPN с официальной поддержкой Linux.

## Подключение

1. Участники должны находиться в одной и той же приватной VPN-сети.
2. На серверном компьютере запусти `chmod +x run-radmin-vpn.sh && ./run-radmin-vpn.sh`.
3. Найди строку `Radmin VPN: http://26.x.x.x:5080/InMusic` и передай адрес только участникам сети.
4. На других компьютерах открой этот адрес в браузере.
5. Если включён firewall, разреши TCP 5080 только из VPN-подсети. Не отключай firewall целиком.

Например, если твоя проверенная VPN-подсеть — 26.0.0.0/8, правило UFW: `sudo ufw allow from 26.0.0.0/8 to any port 5080 proto tcp`. Сначала проверь реальный адрес VPN-интерфейса и правила своей сети.

## Безопасность

- Создай аккаунт администратора до приглашения других участников.
- Используй уникальный пароль и не публикуй имя/пароль VPN-сети.
- Доступ через VPN не равен публичному хостингу. Не открывай порт 5080 в интернет и не настраивай port-forwarding.
- HTTP внутри VPN не даёт HTTPS-защиту браузера; используй только доверенную приватную сеть.
