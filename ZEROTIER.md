# InMusic через ZeroTier (Linux)

Этот скрипт запускает InMusic на `0.0.0.0` и выводит только IPv4-адреса активных интерфейсов Linux, имена которых начинаются с `zt` (типичные интерфейсы ZeroTier). Это адреса, которые можно открыть на телефоне или другом компьютере, подключённом к той же приватной сети ZeroTier.

## Настройка

1. Установи официальный ZeroTier-клиент на Linux и Android.
2. Создай приватную сеть в ZeroTier Central и подключи к ней Linux-компьютер и Android с одним Network ID.
3. В ZeroTier Central подтверди (Authorize) оба устройства. Убедись, что у них есть адреса и они находятся в одной сети.
4. В каталоге InMusic выполни:

   ```bash
   chmod +x run-zerotier.sh
   ./run-zerotier.sh
   ```

5. Скрипт покажет адрес вида `http://10.x.x.x:5080/InMusic`. Открой его в браузере Android, пока ZeroTier подключён.

## Проверка вручную

```bash
sudo zerotier-cli status
sudo zerotier-cli listnetworks
ip -4 addr
```

У ZeroTier-интерфейса обычно имя `zt` с буквенно-цифровым суффиксом. Если адрес не показан, проверь, что служба ZeroTier работает, устройство авторизовано, сеть подключена и интерфейс поднят.

## Firewall и безопасность

Если включён UFW, не отключай его целиком. Разреши TCP-порт 5080 только из фактической ZeroTier-подсети, указанной в ZeroTier Central. Например, если твоя сеть действительно использует `10.147.20.0/24`:

```bash
sudo ufw allow from 10.147.20.0/24 to any port 5080 proto tcp
```

Не копируй пример подсети без проверки своей конфигурации. Не настраивай проброс порта 5080 на роутере и не публикуй адрес/Network ID открыто. ZeroTier обеспечивает приватную сетевую связность, но само по себе не заменяет пароли пользователей InMusic и HTTPS для недоверенных сетей.

## Важно

Скрипт не устанавливает и не настраивает ZeroTier автоматически: он только обнаруживает уже подключённый интерфейс и запускает InMusic. Окно терминала должно оставаться открытым; остановка — `Ctrl+C`.
