# InMusic 1.14 — дискография артистов

## Что нового
- В профиле артиста дискография разделена на вкладки «Альбомы» и «Синглы».
- Альбомы сортируются по популярности (локальный счётчик прослушиваний браузера), году выпуска от новых к старым и от старых к новым.
- Синглы отображаются отдельно от альбомов.
- Страница релиза показывает тип релиза, обложку, год, длительность и треки.
- Добавлена поддержка папок `Singles` в библиотеке и API.
- Старый формат `Albums/<альбом>/...` и старые API альбомов сохранены.

## Структура альбома
```
Data/All Artists/Имя артиста/Albums/Название альбома/
  album.json
  cover.jpg
  songs/
    01 - Первая песня.mp3
    02 - Вторая песня.mp3
```

## Структура сингла
```
Data/All Artists/Имя артиста/Singles/Название сингла/
  single.json
  cover.jpg
  songs/
    Название сингла.mp3
```

## Пример single.json
```json
{
  "title": "Название сингла",
  "year": "2026",
  "release_date": "2026-11-02",
  "duration": "3 мин 24 сек",
  "cover": "cover.jpg",
  "credits": "Автор текста: ...; музыка: ...",
  "gradient_color": "#6b245f",
  "gradient_opacity": 88
}
```

## Пример album.json
```json
{
  "title": "Название альбома",
  "duration": "42 мин 15 сек",
  "year": "2026",
  "release_date": "2026-06-15",
  "cover": "cover.jpg",
  "credits": "Автор текста: ...; музыка: ...",
  "gradient_color": "#6b245f",
  "gradient_opacity": 88
}
```

Поля `release_date` и `credits` необязательны. Обложка может быть PNG, JPG или WEBP; укажите её имя в `cover`. Песни — MP3.

## Сортировка
Сортировка популярности использует счётчик прослушиваний `localStorage` текущего браузера. Это пока локальная статистика, не общий серверный рейтинг. Если одинаковые названия релизов используются в двух типах, они всё равно различаются в API и путях хранения.
