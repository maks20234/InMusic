# InMusic 1.13 — структура и новые возможности

Основа пакета: доступная в чате сборка InMusic 1.10. Данные из неё сохранены; новая функциональность добавлена поверх неё.

## Новые папки
- `Data/Emojis/` — PNG-эмодзи чата. Добавляй файлы сюда без изменения кода.
- `Data/Rooms/` — JSON-архивы сообщений комнат.
- `Data/All Artists/<Имя>/artist.json` — метаданные артиста: `biography`, `tagline`, `creatorId`, `creatorName`, `createdAt`, `image`.
- `wwwroot/pages/lobby/` — страница лобби, создание артиста, комнаты, чат и голосования.

## Роль «Мастер-контента»
Назначается администратором через панель управления (клавиша P → Пользователи и роли). Создавать артистов и менять их приписки могут `admin` и `content_master`. Проверка прав выполняется на сервере.

## Добавление артиста вручную
Создай `Data/All Artists/<Имя>/artist.json` и папку `Albums`. Пример:
```json
{
  "biography": "Краткая биография",
  "tagline": "Любая приписка над именем",
  "creatorName": "Загружено сервисом",
  "image": "artist.png",
  "banner": "banner.jpg"
}
```
Для пользовательского артиста `creatorName` будет именем создателя. Если поле отсутствует, страница покажет «Загружено сервисом».

## Комнаты
Создание комнаты требует аккаунт. Пароль хранится в виде PBKDF2-хеша. Создатель комнаты получает роль «Админ комнаты», которая не даёт прав на сайте. Голосование длится 15 секунд. Сообщения архивируются в `Data/Rooms/`. Активные комнаты, состав участников и незавершённые голосования хранятся в памяти и сбрасываются при перезапуске сервера.

## Запуск
```bash
chmod +x install-linux.sh run-linux.sh
./install-linux.sh
./run-linux.sh
```
Открой `http://127.0.0.1:5080/InMusic`.

## Публичный запуск
Перед открытием доступа всему интернету настрой HTTPS через доверенный reverse proxy/tunnel, сделай резервную копию `Data/` и проверь права на каталог. Не открывай порт напрямую без TLS и защиты. Публикуй только аудио, на которое есть необходимые права.


## Мастерская (1.13)
Страница `Мастерская` показывается только ролям `admin` и `content_master`. В ней можно создавать артистов и альбомы, загружать портреты и обложки (PNG/JPG/WEBP), загружать MP3-файлы и редактировать приписку артиста. HEX-цвет градиента задаётся как `#RRGGBB` и виден в предпросмотре.

Файлы сохраняются так:
- `Data/All Artists/<Артист>/artist.json` и портрет `artist.png` (или исходное расширение);
- `Data/All Artists/<Артист>/Albums/<Альбом>/album.json` и обложка `cover.<ext>`;
- `Data/All Artists/<Артист>/Albums/<Альбом>/songs/<имя файла>.mp3`.

Загрузка доступна только `admin` и `content_master`; лимит одного запроса — 60 МБ. Выбор песни в комнате открывает поиск по общей библиотеке и передаёт на сервер ID существующего трека. Лайки и подписки меняют состояние кнопки на месте без перерисовки страницы.

## Что изменено в 1.13
- Раздел «Мастерская» вынесен в отдельную страницу и скрыт от ролей без прав.
- Добавлены создание альбомов, загрузка MP3, портретов и обложек, HEX-цвет с живым предпросмотром.
- В лобби выбор трека открывает библиотеку песен с поиском по названию, артисту и альбому.
- Глобальная синхронизация больше не перемонтирует активную страницу при изменениях файлов данных. Лайки, подписки и чат не должны сбрасывать страницу или её локальное состояние.

### Ограничения загрузки
- MP3 до 60 МБ на файл; изображения PNG/JPG/WEBP до 60 МБ.
- Загружаемые песни сохраняются с исходным именем файла; повторная загрузка файла с тем же именем в альбом отклоняется.
- В названии файла песни можно использовать префикс номера трека, например `01 - Название.mp3`.

## ZeroTier на Linux

Для запуска InMusic с выводом VPN-адреса используй `./run-zerotier.sh`. Инструкция по подключению Linux и Android находится в `ZEROTIER.md`. Скрипт показывает только адреса интерфейсов `zt*`.
